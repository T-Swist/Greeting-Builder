# Greeting-Builder
Build a small greeting helper. The main function, createGreeting, should take a person's first name, last name, and time of day, then return one greeting string.

https://t-swist.github.io/Greeting-Builder/

## Features
- Takes first name, last name, and time of day as input
- Returns a formatted greeting string
- Works with any combination of names and time of day
 # How to run it
 - Just need to click on the link because I use prompt and alert with a bit of html
